# Kaş Experiences

One place for everything Kaş — boat trips to Tersane & Üçağız (Kekova), SUP with sea turtles, paragliding from Babadağ, sunset sails, padel, tennis, hikes up Uyuyan Dev, horse riding on Patara beach.

Built for Gül (@supkas07), Kaş, Antalya. May 2026.

**Live app:** https://timzinin.com/kas-activities/
**Telegram Mini App:** https://t.me/kasexperiences_bot/open
**Bot:** [@kasexperiences_bot](https://t.me/kasexperiences_bot)

## Stack
- Single-file HTML prototype (`index.html`) — Mediterranean palette, Fraunces + General Sans, mobile-first
- TWA-ready (Telegram WebApp init inlined)
- Backend (planned): FastAPI + aiogram + SQLite + Iyzico
